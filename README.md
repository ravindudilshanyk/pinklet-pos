# 🧾 Pinklet POS System

A modern **Point of Sale (POS) desktop application** built for **Pinklet Cakes & Gift Shop** to manage billing, inventory, customers, and sales efficiently.

---

## ✨ Overview

Pinklet POS is a full-stack desktop system designed to simplify shop operations such as:
- Fast billing with barcode support
- Inventory tracking
- Customer management
- Sales history & reporting
- Secure authentication system

---

## 🚀 Features

- 🛒 Billing system with real-time cart
- 📦 Inventory & stock management
- 👥 Customer management
- 📊 Sales reports & analytics
- 🔐 Login & role-based access
- 🧾 Custom item & discount support
- 🧑‍💼 Supplier management
- ⚡ Keyboard shortcuts for fast billing
- 💾 Persistent data storage

---

## 🧰 Tech Stack

- ⚡ Electron (Desktop App)
- ⚛️ React (UI)
- 🟦 TypeScript
- 🌐 Express.js (Backend API)
- 🧬 Prisma ORM
- 🐘 PostgreSQL / MySQL
- 📦 pnpm (Package Manager)
